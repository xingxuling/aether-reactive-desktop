# Legacy experiments

These modules are preserved as source material from Aether Desktop Toys v0.1.
They are intentionally not registered in the Aether Reactive Desktop v0.2 primary product.

- `dynamic-cover`: debug preview only; it is not a Windows wallpaper host.
- `music-halo`: v0.1 local-file prototype; the v0.2 runtime owns the primary Music Halo path.
- `project-terrarium`: removed from the primary product after user trial feedback.
- `tree-spirit`: reserved for a future Reactive Character Companion experiment.
- `pocket-world`: paused; its deterministic simulation and persistence remain reusable.

Do not label the v0.1 dynamic-cover preview as `TRUE_WALLPAPER_VERIFIED`.
