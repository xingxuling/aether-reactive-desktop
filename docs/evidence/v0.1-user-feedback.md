# v0.1 用户反馈｜事实记录

本轮重构依据附件中的真实试用反馈，不把主观喜好改写成技术指标。

## 明确失败

- Dynamic Cover 只是普通窗口的假全屏预览，不是真正的 Windows 桌面壁纸，因此记为 `FAIL`。

## 明确无聊或不应占据主入口

- Project Terrarium：用户判断“非常无聊”。
- TreeSpirit：用户判断“非常无聊”。
- Pocket World：用户判断“非常无聊”，但其确定性模拟和持久化实现仍有研究价值。

## 保留但改变方向

- Music Halo 对用户有一定吸引力，因此没有删除；它被升级为 Music Halo Pro，并成为统一 Reactive Runtime 的 P0 声音入口。

## 转化后的产品判断

- 不再用五张 Toy Card 作为首页。
- Dynamic Cover 不能继续以“壁纸”名义展示，必须经过 WorkerW 原生闸门。
- Terrarium、TreeSpirit 移入 legacy；Pocket World 代码保留并暂停主路径。
- Music Halo 从“本地文件视觉玩具”升级为系统声音主路径，Local File 保留为可靠回退。
- 新产品的价值单位从“一个小器物”改为“整个桌面正在回应”。
