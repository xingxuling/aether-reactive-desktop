# Aether Desktop Toys Art Bible

## 视觉母题

quiet futuristic / living system / glass / deep sky / soft light / organic + computational。

## 颜色

- Deep sky：`#071225` → `#172b50`
- Soft light：`#d7f3ff`
- Aether blue：`#73c9ff`
- Subtle gold：`#e8c981`
- Leaf mint：`#9ce6cf`
- Warning coral：`#ff9b8c`

## 动画规则

慢速分层运动、细小随机扰动、可呼吸的亮度、低频环境变化。避免 RGB 跑马灯、持续闪烁和大面积高饱和霓虹。

v0.1 全部视觉由 Canvas 2D 程序化绘制，不依赖外部图片或网络资源；这样能保持安装包轻量，也让状态到视觉的映射可测试。
